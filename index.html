Before you register students, tell the system about your school. You enter this once. It is printed on every visitation card and shown on the Dashboard, and the school initials start every admission number.

You can change everything except the initials later under Card design.

Upload many photos at once

  1. Name each photo after the student, either by admission number (the photo of ABC/0001 is ABC_0001.jpg) or by name (Anna Okello.jpg). Capital letters and the order of the names do not matter.
  2. Choose the photos. Each one is matched to its student and the result for every file is listed.
  3. A photo is only saved when exactly one student matches. If two students have the same name, name that file by admission number. Students who already have a photo are skipped unless you tick "Replace".
Download name list Names and admission numbers, with the file name each photo should have.

One photo for one student? Use the Photo button on that student's row under Students.

Cards

Tick the cards to print, or tick none to print everything that matches the filters. Four cards fit on one A4 page. In the print dialog choose Portrait, Margins: None, and tick Background graphics.

Promote the whole school

Every student moves up one class and keeps the admission number, photo and details. The stream name stays the same (S1 East becomes S2 East). The move happens all together and can be undone.
